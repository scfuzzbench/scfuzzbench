# Product

## Register

product

## Users

Smart-contract security researchers, fuzzer maintainers, benchmark contributors,
project maintainers, and funders use the public documentation on desktop and
mobile. They need to inspect benchmark evidence, understand how runs are funded,
and verify project spending without relying on private context.

## Product Purpose

scfuzzbench is a current, practical benchmark for smart-contract fuzzers. It
publishes reproducible methodology, raw artifacts, comparative results, and
project-level financial data so the community can independently review both the
benchmark and the resources used to operate it.

## Brand Personality

Rigorous, transparent, and calm. The interface should communicate technical
confidence through clear evidence and precise language, not promotional claims.

## Anti-references

Avoid opaque grant marketing, speculative crypto styling, vanity metrics, noisy
finance dashboards, material-style decoration, and charts that expose more
detail than the reader needs. Do not present round-wide or ecosystem-wide totals
as though they belong to scfuzzbench.

## Design Principles

- Show evidence before making claims.
- Scope every number to scfuzzbench.
- Make the primary fact clear before supporting detail.
- State estimates, partial data, and source limits in plain language.
- Use responsive structure so the same task stays clear on any screen.

## Accessibility & Inclusion

Target WCAG AA contrast and interaction behavior. Preserve keyboard and screen
reader access, never rely on color alone, respect reduced-motion preferences,
and keep financial labels understandable without chart interpretation.
